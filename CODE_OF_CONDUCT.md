# Code of conduct

falcon-grid adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. In short:

- Be respectful and welcoming. Assume good faith, and critique code, not people.
- No harassment, insults, sexualised language or imagery, or personal attacks, in any project
  space: issues, pull requests, discussions and anywhere you represent the project.
- Don't publish anyone's private information without their explicit permission.

## Reporting

Report unacceptable behaviour privately to the maintainer through the contact details on their
GitHub profile (https://github.com/matthewfuaux). Reports are handled confidentially. The
maintainer may remove comments, close threads, or block people who break this code, following
the Covenant's enforcement guidelines (correction, warning, temporary ban, permanent ban).
